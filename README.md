# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.

✈️ TripCraft — Trip Itinerary Planner & Travel Expense Analytics

Plan your trips. Organize your days. Track your budget.

TripCraft is a full-stack web application designed to simplify travel planning by combining itinerary management, expense tracking, and data analytics in one platform.

The project integrates Advance Programming (AP) and Data Engineering (DE) concepts through REST API development, database management, CSV data processing, data cleaning, and SQL-based analytics.

📌 Problem Statement

Planning a trip involves organizing destinations, activities, travel schedules, and expenses across multiple sources. Managing these details manually can be time-consuming and makes it difficult to monitor travel budgets.

TripCraft provides a centralized platform to organize itineraries, manage expenses, and analyze travel costs efficiently.

💡 Key Features

🗺️ Trip Management: Create, update, view, and delete trips.

📅 Daily Itinerary: Organize activities by date and destination.

💰 Expense Tracking: Record expenses for food, transport, accommodation, and activities.

📊 Budget Analytics: Compare planned budgets with actual expenses.

📁 CSV Import: Import destination datasets from CSV files.

🔄 Data Processing: Clean, validate, and transform destination records.

🗄️ Database Management: Store trips, activities, expenses, and destinations in PostgreSQL.

📈 Visual Analytics: Display spending breakdowns and trip summaries through charts.
