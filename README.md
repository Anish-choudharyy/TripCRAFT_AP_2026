# ✈️ TripCraft — Trip Itinerary Planner & Travel Expense Analytics

**Plan your trips. Organize your days. Track your budget.**

TripCraft is a travel planning web application designed to help users organize itineraries, manage expenses, and understand their travel costs in one place.

## 📌 Problem Statement

Planning a trip involves organizing destinations, activities, schedules, and expenses across multiple sources. Managing these details manually can be time-consuming and makes it difficult to monitor the overall budget.

TripCraft aims to provide a centralized platform for planning trips, organizing daily activities, tracking expenses, and analyzing travel costs.

## 💡 Key Features

- 🗺️ **Trip Management:** Create, view, update, and delete trips.
- 📅 **Daily Itinerary:** Organize activities by date and destination.
- 💰 **Expense Tracking:** Record expenses for food, transport, accommodation, and activities.
- 📊 **Budget Analytics:** Compare planned budgets with actual expenses.
- 📁 **CSV Import:** Import destination datasets from CSV files.
- 🔄 **Data Processing:** Clean, validate, and transform destination records.
- 🗄️ **Database Management:** Store trip-related data in PostgreSQL.
- 📈 **Visual Analytics:** Display spending breakdowns and trip summaries through charts.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Animations:** Framer Motion
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Charts:** Recharts
- **Version Control:** Git and GitHub

## 🎯 Project Goals

- Make travel planning more organized.
- Help users manage travel budgets.
- Practice frontend and backend development.
- Apply database management and data engineering concepts.
- Explore data processing and SQL-based analytics.

## 🚧 Project Status

The current stage focuses on the frontend homepage and user interface. Additional features, including destination discovery, itinerary management, expense tracking, and analytics, can be developed incrementally.
